# Accessibility (a11y) & Keyboard Navigation

Aplikasi HRIS sering digunakan oleh *Data Entry* atau *Admin* yang sangat mengandalkan navigasi **Keyboard**. UI tidak hanya harus cantik, tapi juga fungsional tanpa mouse.

## 1. Interaktifitas Dasar (Tabbing)

- Semua elemen interaktif (tombol, link, input) harus bisa diakses menggunakan tombol `Tab`.
- Komponen *custom* interaktif (misalnya custom Datatable row yang bisa diklik atau Custom Dropdown) harus diberi atribut `tabindex="0"` jika tidak menggunakan tag bawaan seperti `<button>` atau `<a>`.

### ✅ Correct
```svelte
<div 
    role="button" 
    tabindex="0" 
    onclick={handleAction} 
    onkeydown={(e) => (e.key === 'Enter' || e.key === ' ') && handleAction()}
>
    Custom Button Element
</div>
```

## 2. ARIA Labels

- Gunakan `aria-label` untuk setiap tombol yang hanya berisi icon (tanpa teks deskriptif).
  
### ✅ Correct
```svelte
<button aria-label="Tutup modal" onclick={closeModal}>
    <Icon icon="lucide:x" />
</button>
```

## 3. Focus Trapping pada Dialog

- Ketika Modal/Dialog/Drawer terbuka, navigasi `Tab` tidak boleh "bocor" (keluar) dari dalam modal ke elemen *background*.
- *Focus* pertama harus otomatis diarahkan ke input pertama di dalam modal tersebut.
